# The NAME SURFACE: every filter, function and test name any of the three
# sources binds -- the engine, egret, and minijinja's own defaults -- and, for
# every name BOTH bind, the corpus entry that compares them.
#
# W2 Task 8 and its fix round. Twenty times this package has found a name
# minijinja binds that Kestra also binds, RESOLVING to minijinja's answer
# instead of erroring as unknown: `string` and `indent` (Task 4), `range`
# (Task 7), `replace` (Task 8), and sixteen more Pebble-core filters its fix
# round measured -- 104 differential probes, 52 of them divergent. Each was
# invisible because minijinja ANSWERED. This file is the fixture for both
# halves of that question: which names does each side have, and what compares
# the ones they share?
#
# `runners::env::the_built_in_surface_matches_the_engines` asserts every row by
# probing egret through `render_str`, and
# `runners::env::no_name_egret_binds_is_missing_from_the_surface_fixture`
# asserts that no name egret binds is MISSING one:
#
#   - a name the file says egret binds that egret does not fails, by name;
#   - a name the file says egret does not bind that egret does fails, by name;
#   - a name egret binds with no row at all fails -- the functions enumerated
#     exactly from `Environment::globals()`, the filters and tests computed
#     from minijinja's pinned defaults minus the removal lists, plus every
#     `add_*` call scanned out of the committed source;
#   - a row whose two columns DIFFER must carry a reason, and so must a
#     `no`/`no` row, which exists only because egret REMOVED a minijinja
#     default;
#   - a BOTH-BIND row must name a corpus entry, and its reason must be `-`
#     exactly when that entry is not in `baseline.txt`. So a divergence on a
#     shared name is recorded where the RATCHET holds it, not in prose;
#   - the engine-side counts must equal `host.Oracle dump`'s (63 filters,
#     37 functions, 8 tests).
#
# **The `no`/`no` rows are why this file is longer than either engine's
# inventory, and they were added because a mutant survived without them.**
# The first cut listed only the names one side or the other binds, so
# re-registering a removed minijinja filter (`groupby`) produced no row and no
# failure -- an over-acceptance the fixture existed to catch, invisible to the
# fixture. Every removed default now has a row.
#
# Format: `<kind> <name> <engine> <egret> <semantics> <reason>`, tab-separated.
#   kind       filter | function | test
#   engine     does io.kestra:core:2.0.0-rc13 + Pebble 4.1.2 bind this name --
#              MEASURED, by instantiating CoreExtension, EscaperExtension,
#              I18nExtension and io.kestra.core.runners.pebble.Extension and
#              reading their getFilters()/getFunctions()/getTests() maps
#   egret      does egret bind it, after `runners::env::environment()`
#   semantics  both-bind rows only: a `corpus.json` id that compares the two
#              engines on this name. **A BASELINED id is preferred where the
#              name has one**, so the row surfaces a known divergence rather
#              than hiding it behind a passing sibling. `-` on every other row
#   reason     `-` when both bind it and the named entry passes; what differs
#              otherwise
#
# A row names ONE entry. It does not claim that entry is the only comparison
# for that name -- `filter-date` has 166 of them -- only that the name is
# compared and that the ratchet holds what the row says about it.
#
# Six of minijinja's test names -- `==`, `!=`, `<`, `<=`, `>`, `>=` -- have no
# row: minijinja's `is` operator parses an identifier, so they are unreachable
# from template syntax with or without them registered, and a row nothing can
# probe is a claim rather than an assertion. `egret context scope`, the global
# `runners::functions::fetch_context` reads the render context's own names
# from, has none for the same reason: its name contains a space. Both are
# pinned by tests.
