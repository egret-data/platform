# The NAME SURFACE: every filter, function and test name any of the three
# sources binds -- the engine, egret, and minijinja's own defaults.
#
# W2 Task 8. Four times this package has found a name minijinja binds that
# Kestra also binds, RESOLVING to minijinja's answer instead of erroring as
# unknown -- `string` and `indent` (Task 4), `range` (Task 7), `replace`
# (Task 8). Each was invisible because minijinja ANSWERED. This file is the
# other half of that question and the fixture that keeps it answered: which
# names does each side have at all?
#
# `runners::env::the_built_in_surface_matches_the_engines` asserts it
# BIDIRECTIONALLY, by probing egret through `render_str` rather than by reading
# a registry:
#
#   - a name the file says egret binds that egret does not fails, by name;
#   - a name the file says egret does not bind that egret does fails, by name;
#   - a row whose two columns DIFFER must carry a reason, and so must a
#     `no`/`no` row, which exists only because egret REMOVED a minijinja
#     default -- so neither a gap nor a removal can be introduced or undone
#     silently;
#   - the engine-side counts must equal `host.Oracle dump`'s (63 filters,
#     37 functions, 8 tests), so a row cannot be deleted to make a failure go
#     away.
#
# **The `no`/`no` rows are why this file is longer than either engine's
# inventory, and they were added because a mutant survived without them.**
# The first cut listed only the names one side or the other binds, so
# re-registering a removed minijinja filter (`groupby`) produced no row and no
# failure -- an over-acceptance the fixture existed to catch, invisible to the
# fixture. Every removed default now has a row.
#
# **This file is about NAME PRESENCE, not about semantics.** A `-` row says
# both engines have the name; it does NOT say they agree about what it does.
# The names both sides have divide into three groups:
#
#   - Kestra's own 35 filters and 34 functions, differentially verified by
#     `corpus.json` -- that is what W2 Tasks 4-8 were;
#   - `indent`, `string`, `range` and `replace`, where egret OVERRIDES
#     minijinja's built-in with Kestra's semantics for exactly this reason;
#   - seventeen more Pebble-core filter names (`abs capitalize default escape
#     first format join last length lower reverse slice sort split title trim
#     upper`) plus four test names (`defined even iterable odd`), where egret
#     is running MINIJINJA's semantics and no task has compared them. See
#     `oracle/README.md`, "The name surface, and what W2 did not compare".
#
# Format: `<kind> <name> <engine> <egret> <reason>`, tab-separated.
#   kind    filter | function | test
#   engine  does io.kestra:core:2.0.0-rc13 + Pebble 4.1.2 bind this name --
#           MEASURED, by instantiating CoreExtension, EscaperExtension,
#           I18nExtension and io.kestra.core.runners.pebble.Extension and
#           reading their getFilters()/getFunctions()/getTests() maps
#   egret   does egret bind it, after `runners::env::environment()`
#   reason  `-` when both sides bind it; why not otherwise
#
# Six of minijinja's test names -- `==`, `!=`, `<`, `<=`, `>`, `>=` -- have no
# row: minijinja's `is` operator parses an identifier, so they are unreachable
# from template syntax with or without them registered, and a row nothing can
# probe is a claim rather than an assertion. That is pinned by
# `the_operator_spelled_tests_are_unreachable_rather_than_removed`.
