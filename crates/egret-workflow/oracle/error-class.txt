# Every corpus entry compared by ERROR CLASS instead of by value.
#
# `compare: "error-class"` means tests/oracle.rs checks only that egret ALSO
# fails, never what it says -- because the golden value is a Java exception
# string no Rust port can reproduce byte for byte.
#
# It is also a FREE PASS: such an entry matches on any error at all, including
# `unknown function`, so it is born matching, never enters oracle/baseline.txt,
# and can never fail. A task that cannot reproduce a filter could mark its
# entry error-class and the oracle would go green on work that was not done.
#
# So adding one is a deliberate, reviewable act: this file is asserted to equal
# the set of markers in corpus.json EXACTLY, which makes a new error-class
# entry a one-line diff here rather than a field edit buried in a 138-entry
# JSON file. The same discipline oracle/baseline.txt applies to mismatches.
#
# One id per line. `#` starts a comment. Corpus order.

# Pebble THROWS on a String/Number comparison; egret coerces. Still
# mismatching -- error-class forgives the message, not the outcome.
gt-mixed
lt-mixed
lte-mixed
gte-mixed

# W2 TASK 4, four wrong-typed-input entries. Their goldens are
# `PebbleException` text and their only reproducible content is "Kestra
# refuses this". Each is backed by a unit test in runners::filters that
# asserts egret's OWN message for the same input, so the free pass is not
# what is carrying them:
#
#   filter-chunk-not-list      -> chunk_rejects_a_non_list
#   filter-distinct-not-list   -> distinct_rejects_a_non_list
#   filter-values-not-map      -> values_rejects_a_non_map
#   filter-number-not-string   -> number_rejects_a_non_string
#
# `distinct` and `chunk` are here for the same reason but say opposite things
# about null: `chunk(null)` is null and `distinct(null)` is the STRING "null",
# so the pair is what makes the asymmetry visible.
filter-chunk-not-list
filter-distinct-not-list
filter-values-not-map
filter-number-not-string
