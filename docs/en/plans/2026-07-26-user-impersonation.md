# User Impersonation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a platform_admin (any user) or ws_admin (a member of a workspace they manage) impersonate that user — full-stack, read-write with both-parties audit, step-up + reason at start, 30-minute cap — to reproduce user-reported problems.

**Architecture:** Impersonation is a **session overlay**: a row keyed to the admin's existing session that makes `SessionService::validate` resolve to the *target's* `Principal` while carrying an `Impersonator`. Because every engine/catalog token and every authz decision is built from the request `Principal`, the data plane, Cedar, RBAC, and UI follow the target identity with no change to the query/token layers. The admin's cookie and session are never swapped or destroyed.

**Tech Stack:** Rust (axum 0.8, sqlx/Postgres, utoipa), React 18 + TypeScript, react-query, orval-generated client, vitest, Playwright.

**Spec:** `docs/en/specs/2026-07-26-user-impersonation-design.md`

`migrations/0095_impersonations.sql`:

```sql
-- An active impersonation overlay on an admin's session. Absence = the session
-- is the admin acting as themselves. At most one active row per admin session.
CREATE TABLE impersonations (
    id                 UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
    admin_session_id   UUID        NOT NULL REFERENCES sessions(id) ON DELETE CASCADE,
    impersonator_id    UUID        NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    target_user_id     UUID        NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    -- NULL = unrestricted (platform_admin). Non-NULL = ws_admin, confined here.
    workspace_scope_id UUID        REFERENCES workspaces(id) ON DELETE CASCADE,
    reason             TEXT        NOT NULL,
    started_at         TIMESTAMPTZ NOT NULL DEFAULT now(),
    expires_at         TIMESTAMPTZ NOT NULL
);

CREATE UNIQUE INDEX impersonations_one_per_session ON impersonations (admin_session_id);

-- Every audited mutation made while impersonating records the real admin behind
-- the target identity it ran as. NULL for ordinary (non-impersonated) actions.
ALTER TABLE audit.audit_log ADD COLUMN impersonator UUID;
```

Note the audit table is `audit.audit_log` (schema-qualified — confirm the exact schema with `\d audit.audit_log` if the `ALTER` errors; the audit crate creates it).

```rust
//! The impersonation overlay store. An overlay row makes `SessionService::validate`
//! resolve an admin's session to the target user's `Principal` (see session.rs),
//! while remembering the admin. At most one active row per admin session.

use egret_core::{Error, Result, UserId, WorkspaceId};
use egret_metastore::Db;
use uuid::Uuid;

#[derive(Clone)]
pub struct ImpersonationRepo {
    db: Db,
}

pub struct NewImpersonation {
    pub admin_session_id: Uuid,
    pub impersonator_id: UserId,
    pub target_user_id: UserId,
    pub workspace_scope: Option<WorkspaceId>,
    pub reason: String,
    pub ttl_minutes: i64,
}

/// A currently-active (non-expired) overlay, as read by `validate`.
#[derive(Debug, Clone, sqlx::FromRow)]
pub struct ActiveImpersonation {
    pub impersonator_id: Uuid,
    pub target_user_id: Uuid,
    pub workspace_scope_id: Option<Uuid>,
    pub expires_at: chrono::DateTime<chrono::Utc>,
}

fn db_err(e: sqlx::Error) -> Error {
    Error::Internal(anyhow::anyhow!(e))
}

impl ImpersonationRepo {
    pub fn new(db: Db) -> Self {
        Self { db }
    }

    /// Insert an overlay. The unique index on `admin_session_id` rejects a second
    /// active overlay on the same session (→ Err), which enforces no-nesting.
    pub async fn start(&self, n: NewImpersonation) -> Result<()> {
        sqlx::query(
            "INSERT INTO impersonations \
             (admin_session_id, impersonator_id, target_user_id, workspace_scope_id, reason, expires_at) \
             VALUES ($1, $2, $3, $4, $5, now() + make_interval(mins => $6))",
        )
        .bind(n.admin_session_id)
        .bind(n.impersonator_id.0)
        .bind(n.target_user_id.0)
        .bind(n.workspace_scope.map(|w| w.0))
        .bind(&n.reason)
        .bind(n.ttl_minutes)
        .execute(&self.db.pool)
        .await
        .map_err(db_err)?;
        Ok(())
    }

    /// The active (non-expired) overlay for `admin_session_id`, if any. Expired
    /// rows are treated as absent AND best-effort deleted (the auto-return path).
    pub async fn active_for_session(&self, admin_session_id: Uuid) -> Result<Option<ActiveImpersonation>> {
        let row = sqlx::query_as::<_, ActiveImpersonation>(
            "SELECT impersonator_id, target_user_id, workspace_scope_id, expires_at \
             FROM impersonations WHERE admin_session_id = $1 AND expires_at > now()",
        )
        .bind(admin_session_id)
        .fetch_optional(&self.db.pool)
        .await
        .map_err(db_err)?;

        if row.is_none() {
            // Reap an expired overlay if one is sitting here (ignore errors — this
            // is on the hot validate path and must never fail the request).
            let _ = sqlx::query("DELETE FROM impersonations WHERE admin_session_id = $1 AND expires_at <= now()")
                .bind(admin_session_id)
                .execute(&self.db.pool)
                .await;
        }
        Ok(row)
    }

    pub async fn exit(&self, admin_session_id: Uuid) -> Result<()> {
        sqlx::query("DELETE FROM impersonations WHERE admin_session_id = $1")
            .bind(admin_session_id)
            .execute(&self.db.pool)
            .await
            .map_err(db_err)?;
        Ok(())
    }
}
```

```rust
#[derive(serde::Deserialize, utoipa::ToSchema)]
pub struct StartImpersonation {
    pub target_user_id: String,
    pub reason: String,
    /// Required for a local-auth admin (step-up). OIDC admins re-auth via `/oidc/login`.
    pub password: Option<String>,
}

async fn impersonate_start(
    State(st): State<AuthState>,
    Auth(p): Auth,
    jar: axum_extra::extract::cookie::CookieJar,
    Json(body): Json<StartImpersonation>,
) -> Result<Json<serde_json::Value>, AuthError> {
    // 0. No nesting.
    if p.impersonator.is_some() {
        return Err(AuthError(Error::Forbidden));
    }
    // 1. Platform authorization.
    if !p.platform_roles.iter().any(|r| r == "platform_admin") {
        return Err(AuthError(Error::Forbidden));
    }
    // 2. Parse + self-check.
    let target_id = UserId(parse_uuid(&body.target_user_id)?);
    if target_id == p.user_id {
        return Err(AuthError(Error::InvalidInput("cannot impersonate yourself".into())));
    }
    if body.reason.trim().is_empty() {
        return Err(AuthError(Error::InvalidInput("reason is required".into())));
    }
    // 3. Step-up (local admins). See Task 8 for OIDC.
    let admin = st.users.find_by_id(p.user_id).await.map_err(AuthError)?
        .ok_or(AuthError(Error::Unauthorized))?;
    if admin.provider == "local" {
        let pw = body.password.as_deref().unwrap_or("");
        let ok = admin.password_hash.as_deref()
            .map(|h| egret_auth::password::verify_password(pw, h).unwrap_or(false))
            .unwrap_or(false);
        if !ok { return Err(AuthError(Error::Unauthorized)); }
    } else {
        // OIDC step-up handled in Task 8; until then, reject to avoid a weaker path.
        return Err(AuthError(Error::InvalidInput("OIDC step-up required".into())));
    }
    // 4. Target must exist and not be a platform_admin.
    let target = st.users.find_by_id(target_id).await.map_err(AuthError)?
        .ok_or(AuthError(Error::NotFound("user".into())))?;
    if st.sessions.platform_roles_public(target_id).await // small pub wrapper over the private helper
        .map_err(AuthError)?.iter().any(|r| r == "platform_admin") {
        return Err(AuthError(Error::Forbidden));
    }
    // 5. Attach the overlay to THIS session.
    let sid = session_id_from_cookie(&jar, &st).await?; // hash the session cookie, SELECT id
    st.impersonations.start(NewImpersonation {
        admin_session_id: sid, impersonator_id: p.user_id, target_user_id: target_id,
        workspace_scope: None, reason: body.reason.clone(), ttl_minutes: 30,
    }).await.map_err(AuthError)?;
    // 6. Audit.
    st.audit.emit(egret_audit::AuditEvent::Mutation {
        actor: Some(p.user_id.0), impersonator: Some(p.user_id.0), workspace_id: None,
        action: "impersonation.start".into(), resource_type: "user".into(),
        resource_id: Some(target_id.0.to_string()),
        detail: serde_json::json!({ "reason": body.reason, "scope": "platform" }),
    });
    Ok(Json(serde_json::json!({ "ok": true })))
}

async fn impersonate_exit(
    State(st): State<AuthState>,
    Auth(_p): Auth,
    jar: axum_extra::extract::cookie::CookieJar,
) -> Result<Json<serde_json::Value>, AuthError> {
    let sid = session_id_from_cookie(&jar, &st).await?;
    st.impersonations.exit(sid).await.map_err(AuthError)?;
    st.audit.emit(egret_audit::AuditEvent::Mutation {
        actor: None, impersonator: None, workspace_id: None,
        action: "impersonation.end".into(), resource_type: "user".into(),
        resource_id: None, detail: serde_json::json!({}),
    });
    Ok(Json(serde_json::json!({ "ok": true })))
}
```

## Notes for the reviewer

Security-critical surface. The points most worth adversarial review:

1. **The overlay is applied only for the admin's own session** (Task 4) — verify there is no path where an impersonated request can attach a second overlay (no-nesting), and that an expired overlay never yields the target.
2. **ws_admin containment** (Task 9) — verify Alice-as-Bob genuinely cannot reach W2 by any route (WsContext denies before membership), and cannot mint a W2 engine token. Try it.
3. **Target guards** — cannot impersonate a platform_admin or self, from either entry point; a ws_admin cannot impersonate another ws_admin.
4. **Step-up** actually blocks — wrong password / no fresh OIDC auth → no overlay written.
5. **Audit** records both parties for a mutation performed while impersonating.
6. The data plane follows for free **only because** engine tokens are minted from the request principal — confirm no token path caches the pre-impersonation identity.
