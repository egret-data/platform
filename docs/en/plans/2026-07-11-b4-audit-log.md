**Goal:** Record every PDP decision (allow + deny) and every grant mutation into an append-only `audit.audit_log`, via an `AuditingPdp` decorator (zero PEP churn) + handler-emitted mutation events feeding one async best-effort sink, with a retention prune and a platform-admin query API.

**Architecture:** A new `egret-audit` crate holds `AuditEvent`, an `AuditSink` (bounded `tokio::mpsc`, `try_send` = drop-on-full), a background batch writer, and an `AuditStore` (insert/query/prune). `egret-auth`'s `AuditingPdp` wraps `CedarPdp` behind the shared `Arc<dyn Pdp>` and emits a Decision per `authorize`. The grant-mutation handlers emit a Mutation. egret-bin builds the sink, spawns the writer + prune, and wraps the PDP. A `GET /control-plane/audit` reads it back.

**Tech Stack:** Rust (axum, sqlx, tokio mpsc), Postgres (`audit` schema).

```rust
//! Append-only audit trail: an async best-effort sink + a batch writer + a store.
use egret_metastore::Db;
use tokio::sync::mpsc;
use uuid::Uuid;

/// One audit event. Decisions come from the PDP decorator; mutations from the
/// grant-change handlers.
#[derive(Debug, Clone)]
pub enum AuditEvent {
    Decision {
        actor: Option<Uuid>, workspace_id: Option<Uuid>, action: String,
        resource_type: String, resource_id: Option<String>, allow: bool, reasons: Vec<String>,
    },
    Mutation {
        actor: Option<Uuid>, workspace_id: Option<Uuid>, action: String,
        resource_type: String, resource_id: Option<String>, detail: serde_json::Value,
    },
}

/// Non-blocking best-effort sink. `emit` never awaits or fails the caller.
#[derive(Clone)]
pub struct AuditSink {
    tx: mpsc::Sender<AuditEvent>,
}

impl AuditSink {
    /// Build a sink + its receiver. The caller spawns `AuditWriter::run(rx, ...)`.
    pub fn new(capacity: usize) -> (Self, mpsc::Receiver<AuditEvent>) {
        let (tx, rx) = mpsc::channel(capacity);
        (Self { tx }, rx)
    }
    /// Emit best-effort: on a full channel the event is dropped + a warn logged.
    pub fn emit(&self, ev: AuditEvent) {
        if self.tx.try_send(ev).is_err() {
            tracing::warn!("audit channel full or closed; event dropped");
        }
    }
}

/// A stored audit row (query result).
#[derive(Debug, Clone, sqlx::FromRow, serde::Serialize)]
pub struct AuditRow {
    pub id: i64,
    pub ts: chrono::DateTime<chrono::Utc>,
    pub kind: String,
    pub actor_user_id: Option<Uuid>,
    pub workspace_id: Option<Uuid>,
    pub action: String,
    pub resource_type: String,
    pub resource_id: Option<String>,
    pub decision: Option<String>,
    pub reasons: Option<Vec<String>>,
    pub detail: serde_json::Value,
}

/// Filters for the query API. `None` = unfiltered.
#[derive(Debug, Clone, Default)]
pub struct AuditQuery {
    pub actor: Option<Uuid>,
    pub action: Option<String>,
    pub kind: Option<String>,
    pub decision: Option<String>,
    pub workspace: Option<Uuid>,
    pub from: Option<chrono::DateTime<chrono::Utc>>,
    pub to: Option<chrono::DateTime<chrono::Utc>>,
    /// Keyset cursor: return rows strictly older than (ts, id).
    pub before: Option<(chrono::DateTime<chrono::Utc>, i64)>,
    pub limit: i64,
}

#[derive(Clone)]
pub struct AuditStore {
    db: Db,
}

impl AuditStore {
    pub fn new(db: Db) -> Self {
        Self { db }
    }

    /// Multi-row INSERT of a batch of events.
    pub async fn insert_batch(&self, events: &[AuditEvent]) -> Result<(), sqlx::Error> {
        if events.is_empty() {
            return Ok(());
        }
        let mut qb = sqlx::QueryBuilder::new(
            "INSERT INTO audit.audit_log \
             (kind, actor_user_id, workspace_id, action, resource_type, resource_id, decision, reasons, detail) ",
        );
        qb.push_values(events, |mut b, ev| match ev {
            AuditEvent::Decision { actor, workspace_id, action, resource_type, resource_id, allow, reasons } => {
                b.push_bind("decision")
                    .push_bind(*actor)
                    .push_bind(*workspace_id)
                    .push_bind(action)
                    .push_bind(resource_type)
                    .push_bind(resource_id)
                    .push_bind(if *allow { "allow" } else { "deny" })
                    .push_bind(reasons)
                    .push_bind(serde_json::json!({}));
            }
            AuditEvent::Mutation { actor, workspace_id, action, resource_type, resource_id, detail } => {
                b.push_bind("mutation")
                    .push_bind(*actor)
                    .push_bind(*workspace_id)
                    .push_bind(action)
                    .push_bind(resource_type)
                    .push_bind(resource_id)
                    .push_bind(Option::<String>::None) // decision
                    .push_bind(Option::<Vec<String>>::None) // reasons
                    .push_bind(detail);
            }
        });
        qb.build().execute(&self.db.pool).await?;
        Ok(())
    }

    /// Filtered, keyset-paginated, newest-first query.
    pub async fn query(&self, q: &AuditQuery) -> Result<Vec<AuditRow>, sqlx::Error> {
        let mut qb = sqlx::QueryBuilder::new("SELECT * FROM audit.audit_log WHERE 1=1");
        if let Some(a) = q.actor { qb.push(" AND actor_user_id = ").push_bind(a); }
        if let Some(a) = &q.action { qb.push(" AND action = ").push_bind(a.clone()); }
        if let Some(k) = &q.kind { qb.push(" AND kind = ").push_bind(k.clone()); }
        if let Some(d) = &q.decision { qb.push(" AND decision = ").push_bind(d.clone()); }
        if let Some(w) = q.workspace { qb.push(" AND workspace_id = ").push_bind(w); }
        if let Some(f) = q.from { qb.push(" AND ts >= ").push_bind(f); }
        if let Some(t) = q.to { qb.push(" AND ts <= ").push_bind(t); }
        if let Some((ts, id)) = q.before {
            qb.push(" AND (ts, id) < (").push_bind(ts).push(", ").push_bind(id).push(")");
        }
        qb.push(" ORDER BY ts DESC, id DESC LIMIT ").push_bind(q.limit.clamp(1, 500));
        qb.build_query_as::<AuditRow>().fetch_all(&self.db.pool).await
    }

    /// Delete rows older than `retention_days`; returns the deleted count.
    pub async fn prune(&self, retention_days: i64) -> Result<u64, sqlx::Error> {
        let res = sqlx::query("DELETE FROM audit.audit_log WHERE ts < now() - make_interval(days => $1)")
            .bind(retention_days.max(0) as i32)
            .execute(&self.db.pool)
            .await?;
        Ok(res.rows_affected())
    }
}

/// Background batch writer. Owns the receiver; drains + inserts in batches.
pub struct AuditWriter;

impl AuditWriter {
    /// Run until the sink is dropped (channel closes). Batches by size or interval.
    pub async fn run(mut rx: mpsc::Receiver<AuditEvent>, store: AuditStore, batch_size: usize, flush: std::time::Duration) {
        let mut buf: Vec<AuditEvent> = Vec::with_capacity(batch_size);
        loop {
            let deadline = tokio::time::sleep(flush);
            tokio::pin!(deadline);
            tokio::select! {
                got = rx.recv() => match got {
                    Some(ev) => {
                        buf.push(ev);
                        if buf.len() >= batch_size {
                            if let Err(e) = store.insert_batch(&buf).await { tracing::warn!(error=%e, "audit insert failed"); }
                            buf.clear();
                        }
                    }
                    None => { // channel closed: final flush
                        if !buf.is_empty() { let _ = store.insert_batch(&buf).await; }
                        break;
                    }
                },
                _ = &mut deadline => {
                    if !buf.is_empty() {
                        if let Err(e) = store.insert_batch(&buf).await { tracing::warn!(error=%e, "audit insert failed"); }
                        buf.clear();
                    }
                }
            }
        }
    }
}
```

```rust
//! A `Pdp` decorator that emits an audit Decision event per authorize, then
//! returns the inner decision verbatim (observation only — parity unchanged).
use std::sync::Arc;

use egret_audit::{AuditEvent, AuditSink};
use egret_core::authz::{Decision, Pdp, Resource, Subject};

pub struct AuditingPdp {
    inner: Arc<dyn Pdp>,
    sink: AuditSink,
}

impl AuditingPdp {
    pub fn new(inner: Arc<dyn Pdp>, sink: AuditSink) -> Self {
        Self { inner, sink }
    }
}

#[async_trait::async_trait]
impl Pdp for AuditingPdp {
    async fn authorize(&self, subject: &Subject, action: &str, resource: &Resource) -> egret_core::Result<Decision> {
        let decision = self.inner.authorize(subject, action, resource).await?;
        self.sink.emit(AuditEvent::Decision {
            actor: Some(subject.user_id.0),
            workspace_id: resource.workspace_id().map(|w| w.0),
            action: action.to_string(),
            resource_type: resource.type_str().to_string(),
            resource_id: resource.id_str(),
            allow: decision.allow,
            reasons: decision.reasons.clone(),
        });
        Ok(decision)
    }
}
```

```rust
        ));
        let prune_store = audit_store.clone();

            loop {
                tick.tick().await;
                if let Err(e) = prune_store.prune(retention).await { tracing::warn!(error=%e, "audit prune failed"); }
            }
        });
    }

    // Wrap the Cedar PDP so every authorize is audited (unless disabled).
    let cedar = std::sync::Arc::new(egret_auth::pdp::CedarPdp::build(db.clone(), &bus).await?);
    let pdp: std::sync::Arc<dyn egret_core::authz::Pdp> = if config.audit.enabled {
        std::sync::Arc::new(egret_auth::pdp::AuditingPdp::new(cedar, audit_sink.clone()))
    } else {
        cedar
    };
```

```rust
//! Platform-admin audit-log query API (read-only; append-only store).
use axum::extract::{Query, State};
use axum::{Json, Router};
use axum::routing::get;
use serde::{Deserialize, Serialize};

use crate::{CpError, CpState};
use crate::auth::Auth;

#[derive(Debug, Deserialize, utoipa::ToSchema, utoipa::IntoParams)]
#[serde(rename_all = "camelCase")]
pub struct AuditQueryParams {
    pub actor: Option<uuid::Uuid>,
    pub action: Option<String>,
    pub kind: Option<String>,
    pub decision: Option<String>,
    pub workspace: Option<uuid::Uuid>,
    pub from: Option<chrono::DateTime<chrono::Utc>>,
    pub to: Option<chrono::DateTime<chrono::Utc>>,
    /// Keyset cursor from a prior page's `nextCursor`.
    pub cursor: Option<String>, // "<ts_rfc3339>,<id>"
    pub limit: Option<i64>,
}

#[derive(Debug, Serialize, utoipa::ToSchema)]
#[serde(rename_all = "camelCase")]
pub struct AuditEntryDto {
    pub id: i64,
    pub ts: chrono::DateTime<chrono::Utc>,
    pub kind: String,
    pub actor_user_id: Option<uuid::Uuid>,
    pub workspace_id: Option<uuid::Uuid>,
    pub action: String,
    pub resource_type: String,
    pub resource_id: Option<String>,
    pub decision: Option<String>,
    pub reasons: Vec<String>,
    pub detail: serde_json::Value,
}

#[derive(Debug, Serialize, utoipa::ToSchema)]
#[serde(rename_all = "camelCase")]
pub struct AuditPage {
    pub entries: Vec<AuditEntryDto>,
    pub next_cursor: Option<String>,
}

pub fn audit_router() -> Router<CpState> {
    Router::new().route("/control-plane/audit", get(list_audit))
}

fn parse_cursor(s: &str) -> Option<(chrono::DateTime<chrono::Utc>, i64)> {
    let (ts, id) = s.split_once(',')?;
    Some((ts.parse().ok()?, id.parse().ok()?))
}

#[utoipa::path(
    get, path = "/api/control-plane/audit", tag = "control-plane-audit",
    params(AuditQueryParams),
    responses(
        (status = 200, description = "Audit entries (newest first)", body = AuditPage),
        (status = 401, description = "Not authenticated", body = egret_core::http::ErrorBody),
        (status = 403, description = "Requires platform_admin", body = egret_core::http::ErrorBody),
    ),
)]
async fn list_audit(
    State(st): State<CpState>,
    Auth(p): Auth,
    Query(q): Query<AuditQueryParams>,
) -> Result<Json<AuditPage>, CpError> {
    egret_core::authz::require(&*st.pdp, &p, "role:read").await?;
    let limit = q.limit.unwrap_or(100).clamp(1, 500);
    let query = egret_audit::AuditQuery {
        actor: q.actor, action: q.action, kind: q.kind, decision: q.decision,
        workspace: q.workspace, from: q.from, to: q.to,
        before: q.cursor.as_deref().and_then(parse_cursor),
        limit,
    };
    let rows = st.audit_store.query(&query).await.map_err(|e| CpError::Internal(anyhow::anyhow!(e)))?;
    let next_cursor = if rows.len() as i64 == limit {
        rows.last().map(|r| format!("{},{}", r.ts.to_rfc3339(), r.id))
    } else { None };
    let entries = rows.into_iter().map(|r| AuditEntryDto {
        id: r.id, ts: r.ts, kind: r.kind, actor_user_id: r.actor_user_id, workspace_id: r.workspace_id,
        action: r.action, resource_type: r.resource_type, resource_id: r.resource_id,
        decision: r.decision, reasons: r.reasons.unwrap_or_default(), detail: r.detail,
    }).collect();
    Ok(Json(AuditPage { entries, next_cursor }))
}
```

## Notes for the security review (after Task 6)

Focus: append-only (no API mutates rows; only the writer inserts + the prune deletes); the query API is platform-admin-gated (`require(role:read)` → 403 for non-admins); the actor is always the authenticated principal (decision: `subject.user_id`; mutation: `ctx.principal`) — never a request field; no secret/token/query-data in `detail` (only grant metadata + decision context); best-effort drop is a stated tradeoff (never blocks or fails a request, never weakens enforcement — audit is observational); `AuditingPdp` delegates the decision verbatim so PDP parity is unchanged; the keyset cursor is server-parsed (a malformed cursor is ignored, not injected — it is bound, not interpolated).
