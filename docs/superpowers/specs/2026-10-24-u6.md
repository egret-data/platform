## What each row does

- **KI-008.** For an existing chart, **Update** saves at once (button reads "Saving…" while the request runs). The name was already edited in the toolbar; the description, which only the dialog could edit, gets an inline field under the name. A new chart keeps its Save dialog, which asks for the name it is created under.
- **KI-050.** A series with no breakout is named by its metric's `column_title` (the dataset display name, or the chart's own rename), so the legend and tooltip say **Revenue**; a series rename still wins. The editor passes the same names (from the effective column settings) to `SortRows` and `DrillMenu` through new optional `labels` props. Stored values stay machine names.
- **KI-053.** "color" everywhere in the chart editor's visible copy.
- **KI-054.** The shared waterfall/box plot Axes tab says **X label** / **Y label** and **Y scale**, like the cartesian tab.
- **KI-055.** Same rule as #739: the Trash summary counts no folders, on Charts and Datasets.
- **KI-056.** Before the first run the Steps section says that the steps appear after the first run and that, until they are ordered there or by a sort, the funnel shows them in database order.
- **KI-058.** See the decision below. Applied to table cells, Object detail values and formatted exports; the Separator style control shows the style the column is drawn with.

## Decision: how an identifier is recognised (KI-058)

By name and type together, not by semantic type: an INTEGER type (`tinyint`, `smallint`, `int`, `integer`, `bigint`, `largeint`) and a name that is `id`, ends in `_id`, ends in camel-case `Id`, or ends in `key` (`orderkey`, `custkey`, `order_key`). A `double` named `…key` is a measure and keeps its separators.

Why not a semantic type: egret's vocabulary has no identifier role, so adding one means a backend enum, a CHECK constraint migration and an API change, and every existing dataset (the demo's included) would still show `29,989` until someone set the role. A wrong guess here costs only the thousands separator, unlike the coordinate roles, where a guessed column plots in the wrong place.

The user's choice wins: an identifier has no thousands separator only while no Separator style is stored for it, on the chart or in the dataset's column format. Choosing **100,000.00** brings the separators back.

## Not changed

- The Charts Trash view still offers **+ Chart** (the Dashboards list hid its create button in #739).
