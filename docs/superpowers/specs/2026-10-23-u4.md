# U4: SQL Lab UX (Known-issues fix programme)

Fourteen S3 rows, all reproduced on main `7eaf8c4c` (live on the demo stack, or by code plus a failing test).

| Row | Change |
|---|---|
| KI-082 | Every SQL Lab tab stays mounted; the inactive ones are `hidden`. A tab keeps its result grid, run status, parameter values, filter and editor state. Only the active tab listens for ⌘K. |
| KI-083 | Opening a saved query titles the new tab with the query's name. |
| KI-084 | A name clicked in the Explorer is appended with a space unless the text ends in whitespace, `(` or `.`. |
| KI-085 | An empty result says "The query returned no rows."; "No rows match …" is kept for a filter that matches nothing. |
| KI-089 | Copy and the Export menu say which rows each carries: CSV "all N rows" (server, full result), JSON and TSV "N loaded rows" or "N filtered rows" (the grid). |
| KI-091 | Deleting a snippet asks for confirmation (same dialog as saved queries). |
| KI-092 | New `DELETE /api/ws/{ws}/queries` clears the caller's own history in that workspace (needs `query:run`, like listing it). History tab: **Clear history** with a confirmation. |
| KI-093 | The Saved tab gets a header with the count and a **New folder** button. |
| KI-094 | The tab rename box selects the old name on focus. |
| KI-160 | Explorer search orders by name, then catalog, then schema (Trino), name then schema (StarRocks), so same-named tables come in a fixed order and the `LIMIT 200` set is fixed. |
| KI-161 | Row counts are singular for one row (toolbar status, grid counter, history). |
| KI-162 | The quick chart's Y ticks are round steps (1, 2, 5 × 10ⁿ), whole numbers for a whole-number measure; X labels are rotated only when they do not fit their band. |
| KI-228 | The run status is shown once, on the toolbar next to Run. The second pill in the Results tab strip and the line under the grid are gone. |
| KI-229 | Default split editor 40 % / results 60 % (was 55/45). |

## Decisions

- **KI-092, clear = hide, not delete.** A query row also serves its status, results and CSV by id and the workspace's query count, so clearing sets a new `query.queries.hidden_from_history` flag (migration 0208) on the caller's rows and the History list skips them. The statement is scoped to `user_id = caller`, so no one can clear another user's history; there is no per-user target in the API at all. The 50-entry cap stays; clearing is what lets a user drop test runs.
- **KI-082, keep mounted rather than lift state.** Lifting result/params into the persisted tab state would still lose the grid's sort, filter and the editor's undo stack, and a running query's timer. Monaco's `automaticLayout` re-lays out a shown editor; the completion provider and ⌘↵ action are already scoped per editor.
- **KI-228, which announcement stays.** The toolbar pill, because it is visible whichever bottom tab (History, Saved, Snippets) is open.
