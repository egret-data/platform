## What each row does

- **KI-217.** Every `<select>` becomes `ui/select`. Radix items cannot carry `""`, so "none" values use a named sentinel mapped back to the stored value, or a `SelectValue` placeholder. A new lint rule, `egret/no-native-select`, fails any `<select>` JSX element; FE-FORM-3 is now "Checked by: lint and review" (review still catches a known set typed into a text input). No legacy list: no file is left breaking it.
- **KI-218.** A shared `DateTimePicker` (`ui/date-time-picker.tsx`) on a `Calendar` (`ui/calendar.tsx`). The trigger reads `YYYY-MM-DD HH:mm` in every browser; the popover holds the month grid, an `HH:mm` field (a bad time is reported beside it, FE-FORM-4) and Clear. The audit log's From and To use it; To defaults a picked day to 23:59.
- **KI-012.** Notifications drops its own padding, width and heading icon; the header matches Roles & permissions; Encryption is `ui/select`. Only the tab's content changes: the settings shell and sidebar are U3's.
- **KI-235.** `FilterSettingsPanel` is rebuilt from the card settings panel's parts: a `FIELD_LABEL` label over a full-width `Select` or `Input`, `RadioGroup` for one-of choices, a `Switch` row for Required and for each linked filter, a `SectionLabel` over "Limit this filter's choices". "Where this filter appears" is a grouped `Select`. Required moves up beside Default value, where Metabase puts it.

## Decisions

- **Calendar library.** `react-day-picker` 9.14.0, pinned. It is the calendar shadcn's `Calendar` is built on, and it brings the keyboard grid (arrows, Home/End, PageUp/PageDown) and the labels, which a hand-written grid would have to rebuild. It loads lazily on the first open, so a page that shows a picker does not take it into its first paint.
- **ParameterEditor removed.** Nothing rendered it; only its own test mounted it. Its `OPERATORS` table moves to `chart/dashboard/operators.ts`. Converting a component no screen shows would be dead code kept alive.
- **Time field is text, not `type="time"`.** The browser's time input has the same locale problem as `datetime-local` (12 or 24 hours by locale).
- **Out of scope, recorded:** other `type="date"` and `datetime-local` inputs (dashboard date filter, ShareDialog, client expiry, workflow backfill and executions, KV and run inputs) stay native. The rule names `DateTimePicker` for new code; migrating them is follow-up work.
